# proxylang 项目原则

<a id="c-001"></a>
## C-001 规则组合优先

使用 TypeScript 定义可复用条件、规则块与策略模板。作者声明的规则顺序与出口绑定具有语义，不为了跨平台输出而隐式改写。

<a id="c-002"></a>
## C-002 平台机制与精确目标

共享策略与平台程序分离。编译目标包含引擎、平台和精确版本；不支持的行为必须报告，不能默默丢弃规则或替换机制。

<a id="c-003"></a>
## C-003 秘密与发布边界

编译与静态解释不读取秘密。构建按批次解析秘密，全部目标成功后切换活动产物；失败保留旧产物。生成配置不等于部署或网络接管。

<a id="c-004"></a>
## C-004 契约与证据分离

Concord 管理产品契约、用户用例、源码和测试关系。测试关系、静态解释、原生配置检查与实际网络验收分别陈述，不互相替代。
