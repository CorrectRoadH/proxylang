# 规则片段接入提案

本提案不作为实现契约。用户明确要求优先解决语言如何表达 it-infra 的平台机制，因此暂停外部出口片段 API 和消费方构建迁移。

语言方向见 [平台机制语法](../../research/platform-syntax/README.md)。规则片段 API 只能处理接入，不能代替平台程序、匹配信息来源及资源生命周期的语义设计。
